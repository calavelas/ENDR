ENDR Portal — UI/UX Redesign Plan

Bring the clean, modern feel of the robot-demo mockup to the real developer portal — better hierarchy, accessible status, lighter density — without changing any IDP functionality, routes, or data contracts.

Part 3 of the naming/UI overhaul · plan for review before building · 2026-06-14

✅ Already done (de-cosmic + rename): the portal is at ENDR/portal, the API layer is /api/platform via lib/platform.ts, and there is already a cohesive dark theme in globals.css (no space/cosmic styling left). This redesign builds on that base — it is polish + componentization, not a rewrite.

1 · Goals & principles

  • Mockup-grade polish: card surfaces, clear status, calm spacing, confident typography — the look of the robot-demo, applied to real pages.
  • Preserve all IDP function: same routes, same loadSnapshot() data flow, same create→PR→reconcile→deploy behaviour, same ArgoCD embed. Pure presentation layer.
  • Fix the real weaknesses the current UI has (below), not just repaint.
  • Accessibility: status = icon + colour (not colour alone), larger base type, better contrast.
  • Componentize: replace repeated inline markup with a small set of shared React components, so future pages stay consistent.

The 5 weaknesses this fixes (from the current-UI audit)

  1. Table overload — 7–10 dense columns; health/sync buried among image tag, revision, etc.
  2. Colour-only status — pills fail colour-blind users (no icons/symbols).
  3. Tiny type — headers ~10px, body ~12px; strains readability.
  4. No progressive disclosure — detail pages dump every field (gateway/url/capabilities) even when empty.
  5. Weak onboarding — funny but vague hero, no help text, no empty states.

  • Type scale: body 0.84rem → 0.95rem; table headers 0.7rem → 0.78rem; line-height 1.3 → 1.55 for copy. Add tokens --fs-xs/sm/base/lg/xl.
  • Add an accent token (--accent: #37d3c3) for primary actions/active states (today buttons reuse status colours).
  • Status with icon: standardize ✓ synced/healthy · ⚠ progressing/unknown · ✕ outofsync/degraded, driven by the existing syncTone()/healthTone() helpers in lib/platform.ts (no logic change, just richer rendering).
  • Spacing/radius: keep --radius-*; slightly increase panel padding for breathing room.

7 · Decisions (answered 2026-06-14)

  • Catalog view → cards/table toggle with a view switcher that remembers the preference.
  • Dashboard hero → summary-first: status line + StatCards (total / healthy / needs-attention / data-source).
  • Accent colour → teal #37d3c3 (matches the mockup). Tokenized as --accent.
  • Light mode → out of scope (dark-only for now).
